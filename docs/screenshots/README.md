# Screenshots

These images are generated from `tests/ui_preview.html` with the mock API. The
counters in the settings screenshot (launches, bypass sessions, hours) are demo
values, not real telemetry or global user statistics. Zapret RU has no global
counter and never sends usage data anywhere.

To regenerate them locally, start a static server in the project root and open
`tests/ui_preview.html` at 440×620.
