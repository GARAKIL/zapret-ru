# Changelog

All notable changes are documented here.

## 2.0.0 — 2026-11-26

### Added

- Цельный glass-интерфейс в духе современных лендингов: верхнее меню, крупные
  стеклянные панели, прозрачный логотип без подложки, анимированные обводки и
  градиентные кнопки.
- Большой круглый переключатель защиты и компактная строка состояния.
- Режимы **«Простой / Расширенный»** в верхней панели.
- Метрика **«Пинг»** и авто-проверка сайтов после включения защиты.
- 7 профилей движка 2.0: SNI середина, старт и конец SNI, split 1/2/4 и
  режим без QUIC-фильтра.
- Новые прозрачные `icon.png` / `icon.ico` без фона.

### Changed

- Версия 2.0.0.
- Полностью перестроена оболочка: сайдбар заменён верхней навигацией.
- Обновлены скриншоты, лендинг, README и release notes.

### Fixed

- Пинг и результат проверки теперь видны в простом режиме.
- Контраст и читаемость мелких подписей на тёмном стекле.

## 1.3.0 — 2026-11-26

### Added

- Режим **«Простой / Расширенный»**: на главной остаётся большая кнопка,
  пинг, статистика и две вторичные кнопки; профили и диагностика — в расширенном.
- Большой круглый переключатель защиты и плавные анимации.
- Метрика **«Пинг»** по минимальной задержке проверенных сервисов.
- Профили **«Старт SNI»** и **«Конец SNI»** для DPI, который смотрит не только
  середину имени.
- Кнопка «Подобрать стратегию» прямо на простом экране.
- Скриншоты и release notes 1.3.0.

### Changed

- Версия 1.3.0.
- Автоподбор проверяет 7 профилей.
- Простой режим включён по умолчанию; выбор запоминается локально.
- README обновлён под новые профили и режим интерфейса.

## 1.2.0 — 2026-11-26

### Added

- **Собственный DPI-движок** на WinDivert: SNI-split, HTTP Host split,
  QUIC → TCP и доменные политики. Больше не используется `winws.exe`.
- **Один самодостаточный exe**: PyDivert и подписанный WinDivert64 включены в
  onefile-сборку.
- Большое окно 1120×800 с рабочими кнопками свернуть / развернуть / закрыть.
- Новый тёмный iOS-интерфейс: скругления, градиенты, анимации, минимум кнопок.
- Горячее применение списков без перезапуска движка.
- Автоподбор профилей и отображение статистики пакетов/split/QUIC.
- Скрытый `--engine-smoke` для проверки собранного exe.
- Миграция старых `presets.json` schema 1 в резервную копию.

### Changed

- Версия 1.2.0, новый формат `presets.json` schema 2.
- Режим по умолчанию — «Все программы» с исключениями.
- README, скриншоты и release notes переписаны под собственный движок.
- PyDivert 4.0.1 добавлен в зависимости и lock-файл.
- GitHub Actions обновлены до checkout v7, setup-python v7, CodeQL v4.

### Removed

- Зависимость от `winws.exe`, `cygwin1.dll`, `.bin`-файлов и папки `bin`.
- Старый менеджер процессов winws и его тесты.
- Терминальная 440×620 вёрстка.

## 1.1.0 — 2026-11-25

### Added

- **Автоподбор стратегии**: последовательно запускает все пресеты, проверяет YouTube, Discord и Cloudflare, выбирает лучший и оставляет его активным.
- Локальная статистика использования: запуски лаунчера, сессии обхода, суммарное время в обходе и в лаунчере. Без телеметрии и сетевых отправок.
- Новый терминальный интерфейс в духе CMD/Linux, новый минималистичный логотип и status line.
- Новые иконки приложения, social preview и документация для GitHub.
- GitHub Actions: тесты, сборка тега и публикация SHA-256 checksum.
- `SECURITY.md`, `CONTRIBUTING.md`, issue templates.

### Changed

- Версия приложения 1.1.0.
- Сетевые проверки теперь отображают состояние в формате `[ok] / [fail]`.
- Копирование исходных данных релиза из Nuitka-архива больше не сохраняет read-only-атрибуты.
- `settings.json` читается с поддержкой UTF-8 BOM.

### Fixed

- CSP `'unsafe-eval'` для локального PyWebView js_api-моста.
- Выбор режима обхода теперь надёжно обновляется в интерфейсе.
- Улучшена остановка и статистика после неожиданного завершения winws.
